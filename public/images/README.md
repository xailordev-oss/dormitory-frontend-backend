# ຮູບສະໄລ້ໂຊ

ວາງຮູບຫໍພັກໄວ້ໃນໂຟນເດີນີ້ (`public/images/`) ແລ້ວມັນຈະຂຶ້ນເປັນສະໄລ້ໂຊ **ໜ້າເຂົ້າສູ່ລະບົບ** ແລະ **ໜ້າຫຼັກ** ເອງ. ບໍ່ຕ້ອງແກ້ code ແລະ ບໍ່ຕ້ອງ build ໃໝ່ (ພຽງ refresh ໜ້າເວັບ).

- ຮອງຮັບ: `.jpg` `.jpeg` `.png` `.webp` `.avif` `.gif`
- ລຽງຕາມຊື່ໄຟລ໌: ຕັ້ງຊື່ `01.jpg`, `02.jpg`, `03.jpg`... ເພື່ອກຳນົດລຳດັບ
- ຂະໜາດແນະນຳ: ຮູບແນວນອນ ກວ້າງ 1600–2400px, ບໍ່ເກີນ 500KB ຕໍ່ຮູບ (ໂຫຼດໄວ)
- ຖ້າບໍ່ມີຮູບເລີຍ ໜ້າເວັບຈະສະແດງພື້ນສີຟ້າແທນ

## ໃສ່ຂໍ້ຄວາມໃຕ້ຮູບ (ທາງເລືອກ)

ສ້າງໄຟລ໌ `slides.json` ໃນໂຟນເດີນີ້. ລຳດັບໃນໄຟລ໌ນີ້ຈະເປັນລຳດັບຂອງສະໄລ້:

```json
[
  { "file": "01.jpg", "title": "ອາຄານ A", "text": "ຫ້ອງພັກ 2 ຄົນ ມີແອ ແລະ ຫ້ອງນ້ຳໃນຕົວ" },
  { "file": "02.jpg", "title": "ພື້ນທີ່ນັ່ງອ່ານປຶ້ມ" }
]
```
